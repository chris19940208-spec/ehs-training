# 安全衛生闖關｜DNN 3F Showroom Safety Quest

在 DNN 3F 展示間的 3D 場景裡走一圈，跟著藍色光圈走到 9 個站點，闖關學會一般安全衛生教育訓練的重點。全部過關後可以下載闖關結業證明。

## 怎麼玩

| 操作 | 電腦 | 手機 |
|------|------|------|
| 看四周 | 拖曳畫面 | 拖曳畫面 |
| 移動 | W A S D 或方向鍵 | 畫面右下方向鍵 |
| 開始關卡 | 站上藍色光圈後按 E | 按「開始關卡」 |
| 直接走到下一站 | 「自動前往」 | 「自動前往」 |

進度存在瀏覽器（localStorage），下次打開會接著玩；「重新開始」會清除進度。

## 關卡

| 關 | 站點 | 主題 | 題型 |
|----|------|------|------|
| 01 | 門口展示櫃台 | 法規基本功（勞工義務、教育訓練時數、職場霸凌） | 單選 |
| 02 | 展示間入口 | 找出危害（延長線串接、堵住安全門、未標示化學品、走道電線） | 場景找危害、單選 |
| 03 | 伺服器機櫃 | 消防大挑戰（拉瞄壓掃、丙類火災、濃煙關門） | 排序、單選 |
| 04 | 展示長桌 | 工作守則與標準作業 | 排序、單選 |
| 05 | Digital Foundry | 客戶廠區作業（承攬、危害告知） | 排序、單選 |
| 06 | SMT AOI 瑕疵檢測 | 化學品通識（危害圖式、安全資料表） | 配對、單選 |
| 07 | 展示櫃台 | 緊急應變（停止作業權、8 小時通報） | 單選 |
| 08 | 訪談區 | 急救（叫叫 CABD、按壓節奏、異物哽塞） | 排序、節奏、單選 |
| 09 | 海報牆與講台 | 結業測驗（5 題答對 4 題） | 單選 |

題目與解說取自「一般安全衛生教育訓練」簡報（2026-11-06 依現行法規編修），法源包括職業安全衛生法（2026-07-01 施行版本）、職業安全衛生教育訓練規則、勞工健康保護規則、危害性化學品標示及通識規則，急救依 2025 年美國心臟協會指引。

## 修改題目

所有站點、關卡與題目都在 `src/levels.js`：

- `mcq`：單選，`answer` 是正確選項的索引（從 0 開始）
- `order`：排序，`items` 依正確順序填寫，遊戲會自動打亂
- `match`：配對，`pairs` 每組是 `[左, 右]`
- `rhythm`：按壓節奏，`min`／`max` 是合格的每分鐘次數
- `hunt`：場景找危害，危害道具的位置寫在 `src/main.js` 的 `buildHazards()`

站點座標是 Blender 座標（x 東、y 北，單位公尺），與展示間模型一致。

```bash
# 開啟 http://localhost:8000
```
